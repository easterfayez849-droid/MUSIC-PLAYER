# CodeAlpha Music Player

A responsive browser-based music player built with HTML, CSS, and vanilla JavaScript.

## Features
- Add multiple audio files from your device
- Playlist with track selection
- Play, pause, previous, and next controls
- Seek/progress bar and elapsed/total time
- Volume control
- Shuffle and repeat modes
- Favorite the current track
- Keyboard shortcuts: Space (play/pause), Left/Right arrows (seek)
- Responsive layout for desktop and mobile

## Run locally
1. Download and extract the project.
2. Open `index.html` in a modern browser.
3. Select **Add music** and choose audio files stored on your device.

The project does not include copyrighted audio. It plays audio files that the user chooses locally; files are not uploaded to a server.

## Technologies
- HTML5
- CSS3
- JavaScript
- HTML Audio API
